# ControlFlow-G

ControlFlow-G is a production-oriented public-data research prototype for governed investigation and simulated remediation of financial-services control exceptions. It combines a local medallion lakehouse, point-in-time features, calibrated risk and anomaly models, temporally and authorization-filtered retrieval, bounded typed tools, deterministic runtime policy, selective human review, evidence verification, durable workflow state, idempotent simulated actions, and append-only audit records.

The project is under active execution. No final metrics or release conclusion are reported until the P25 candidate freeze and one-time P26 locked evaluation. This is an enterprise-style, production-like simulation—not a bank system or real production deployment—and it performs no real financial action.

See [PROJECT_SPEC.md](PROJECT_SPEC.md) for the scientific and execution contract and [state/execution_state.json](state/execution_state.json) for durable progress.
